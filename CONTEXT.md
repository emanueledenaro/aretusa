# Aretusa

Aretusa distributes original interface building blocks with their editable source.

## Language

**Component**:
A reusable interface element with a documented anatomy, states and behavior.

**Block**:
A working composition of components for a page section or application task.

**Registry item**:
A named distributable unit containing source files and declared dependencies.

**Theme**:
A set of visual tokens applied consistently to components and blocks.

**Consumer**:
The project that installs and owns a copy of a registry item's source.

**Catalog entry**:
The shared description connecting an item, its documentation and its live example.
