# Contributing

Open an issue before a substantial addition. Include expected behavior, states, keyboard interaction and a small usage example.

Each component needs source, a catalog entry, live example, installable registry item and behavior tests. Blocks must compile from their declared dependencies. Keep examples fictional and avoid real personal data.

Run the checks listed in package.json before opening a pull request. Include a changelog note for consumer-facing changes. Use small commits and preserve local consumer code in installer changes.
