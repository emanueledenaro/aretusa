# Aretusa

Original React components and Tailwind themes, with source code you can make your own.

By TrinacriaLabs. Named after the Sicilian myth of Aretusa.

## Status

Aretusa is under active development. Installation commands and hosted documentation will be added only when verified releases are available.

## Project

- Original components and reusable page blocks.
- Accessible interaction primitives with an editorial visual style.
- Source-first distribution and an inspectable registry.
- Documentation, examples and installation checks from the same catalog.
